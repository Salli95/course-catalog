# Каталог курсов

Лабораторная работа по веб-разработке. Проект представляет собой каталог учебных курсов с фильтрацией, поиском и детальными страницами.

Стек: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS.

## Основной функционал

- Главная страница со списком ключевых направлений.
- Каталог курсов с поиском по названию, фильтром по типу (все / обязательные / по выбору) и сортировкой (по лайкам, кредитам, алфавиту).
- Все параметры поиска и фильтров сохраняются в строке URL.
- Страница отдельного курса с подробным описанием, списком тем, пререквизитами и блоком похожих курсов.
- Кнопка лайка с локальным подсчетом кликов.
- Страница «О проекте» с описанием целей работы и стека.
- Обработка 404 ошибки для несуществующих курсов и скелетоны загрузки.

## Особенности реализации

- Почти все страницы и компоненты выполнены как Server Components и рендерятся на сервере без лишнего JavaScript на клиенте.
- Единственный клиентский компонент — кнопка лайка (`components/LikeButton.tsx`), в ней используется хук `useState`.
- Страницы курсов собираются заранее через статическую генерацию (`generateStaticParams`).
- Данные курсов и логика фильтрации вынесены в папку `lib/`.
